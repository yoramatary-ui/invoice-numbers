# invoice-numbers

אפליקציית web להטבעת מספרי תעודה מקובץ Excel על קבצי PDF.

## מה זה עושה

1. מעלים קובץ Excel אחד עם שם לקוח ומספר תעודה בכל שורה (העמודות מזוהות אוטומטית לפי כותרות בעברית או באנגלית).
2. מעלים כמה קבצי PDF, כאשר שם הקובץ (ללא הסיומת) תואם לשם באחת השורות באקסל.
3. האפליקציה מוצאת עבור כל PDF את מספר התעודה המתאים ומדביקה אותו בחלק העליון והאמצעי של כל עמוד.
4. מורידים קובץ ZIP עם כל קבצי ה-PDF המעודכנים, תחת אותם השמות המקוריים. אם היו קבצים שלא נמצאה עבורם התאמה, רשימתם תיכלל בקובץ `קבצים-ללא-התאמה.txt` בתוך ה-ZIP.

## הרצה מקומית

```bash
npm install
npm start
```

לאחר מכן פתחו דפדפן בכתובת `http://localhost:3000`.

## בדיקות

```bash
npm test
```
